# Aarogya Voice

A voice-first multilingual health information assistant prototype for India.

## Features
- English, Kannada, Telugu, Hindi and Tamil interface responses
- Text questions and browser speech input/output where supported
- Prepared demo topics: hydration, sleep, blood pressure and chest-pain emergency guidance
- Responsive layout for mobile and desktop

## Run locally
Open `index.html` in a modern browser. Microphone access and speech recognition generally require HTTPS or localhost and browser/device support.

## GitHub Pages
1. Upload all project files while preserving the `css`, `js` and `docs` folders.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch `main` and folder `/ (root)`, then save.
5. Wait for the Pages deployment. The expected URL is `https://YOUR-USERNAME.github.io/aarogya-voice/`.

## Important limitations
This is a student demonstration, not a clinical product and not a generative-AI system. Responses are predefined examples. Speech recognition and available voices vary by browser, operating system and language. It does not diagnose conditions or recommend medication. In an emergency in India, call 112.
